# Envision
### A Visually Motivated Savings Goal Tracker

*See your dreams. Save with purpose.*

## Project Overview

Envision is a full-stack FinTech web application designed to help individuals set personal savings goals, record contributions, and track their financial progress.

The application aims to make saving more meaningful by connecting financial goals with personal motivation.

As an optional feature, users will be able to upload images representing what they are saving for, such as a dream vacation, graduation, or future home.

## Essential Features

- Create personal savings goals with target amounts.
- Record contributions toward existing goals.
- Automatically calculate total savings, remaining balances, and completion percentages.
- View savings goals and progress through a dashboard.

## Optional Feature

- Upload personal motivational images associated with savings goals.

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express
- **Database:** SQLite
- **Version Control:** Git and GitHub
